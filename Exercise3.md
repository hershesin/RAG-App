# Deploy the Application

## Overview

In this section, you will deploy the RAG Chat Application and all its required Azure resources using the Azure Developer CLI (`azd`). The deployment process is automated and will provision all necessary services, configure them, and deploy your application code to Azure. By the end of this step, your application will be live and ready for use in your Azure environment.

# Objectives

By the end of this lab, you will be able to:

- Launch Visual Studio Code and open the lab repository folder.
- Open the integrated terminal and authenticate with Azure using `azd`.
- Verify the lab environment is ready for the next module.

## Deployment Steps

1. From the lab desktop, click the Visual Studio Code icon to open the editor.

1. The VS Code Welcome page appears once the application starts click on **Open Folder(1)**

1. Search for **`azure-search-openai-demo (1)`** folder and click **Select folder (2)**.

1. Open a **new terminal** from the VS Code **Terminal** menu.

>Use the terminal at the bottom of VS Code to run commands.
